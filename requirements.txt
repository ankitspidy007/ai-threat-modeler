## Backend Packages

Install Python dependencies from [backend/requirements.txt](C:/Users/Ankit/Documents/codex/ai-threat-modeler/backend/requirements.txt).

The backend now uses a hybrid NLP stack built around `blingfire`, `transformers`, `sentence-transformers`, and domain-specific rules. Python `3.14` is supported by this stack much more cleanly than the old spaCy-based path.

## Install

```bash
npm install
cd backend
pip install -r requirements.txt
```

No extra spaCy model download is required.
