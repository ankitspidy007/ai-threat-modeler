# Aegis Threat Workspace Requirements

This repository has a React frontend and a FastAPI backend. This file is the
human-readable summary; the authoritative lists are
[package.json](package.json) for the frontend and
[backend/requirements.txt](backend/requirements.txt) for the backend.

## Runtimes

- Node.js >= 18
- npm >= 9
- Python >= 3.10 (tested on 3.12)

## Backend Packages

Install from [backend/requirements.txt](backend/requirements.txt). The local NLP
stack is `blingfire` for segmentation, `sentence-transformers` for semantic
retrieval, `faiss-cpu` for vector search, and a scikit-learn STRIDE classifier.
No spaCy model download is required.

The passes that read architecture descriptions — sentence and clause
segmentation, flow extraction, control polarity, and graph reachability — are
plain Python over the standard library and need no additional packages.

## Install

```bash
npm install
cd backend
pip install -r requirements.txt
```
